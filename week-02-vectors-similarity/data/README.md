### `support_articles.csv` — synthetic help-centre corpus

**Source:** written for this course; generated by `make_support_articles.py`.
**Licence:** CC0 / public domain — it is original course material with no
third-party content.
**Used by:** `lecture-notebook.ipynb` §4.4 (Jaccard vs Hamming), §5.1
(retrieval), §5.2 (cosine as a matmul), §5.3 (near-duplicate detection), §6.3
(averaged word vectors).

Columns:

| Column | Meaning |
|---|---|
| `doc_id` | `KB001`…`KB044`. |
| `category` | One of `shipping`, `returns`, `payments`, `account`, `product_care`. |
| `title` | Article headline. |
| `body` | 33–62 words of help-centre prose. |
| `near_dup_of` | Empty for the 36 base articles; the source `doc_id` for the 8 manufactured near-duplicates. |
| `edit_kind` | Which edit operation produced the duplicate: `synonym_swap`, `reorder_trim`, or `excerpt`. |

**Why synthetic.** The week needs one corpus with three properties at once:
documents short enough that a student can eyeball a retrieval result and judge
it; topic labels; and **near-duplicates whose degree of overlap is known**, so
the Jaccard-on-shingles demo can be *scored* against ground truth instead of
admired. No convenient small public corpus has all three. The generator is
fully deterministic — no RNG anywhere — so re-running it reproduces the CSV
byte for byte.

The three edit operations were chosen to span the difficulty range:
`synonym_swap` (very high overlap, must be caught), `reorder_trim` (moderate),
`excerpt` (low — the hard case, which is what makes the threshold sweep in §5.3
a genuine precision/recall trade-off).

To regenerate:

```bash
uv run python week-02-vectors-similarity/data/make_support_articles.py
```

### `glove_6b_100d_subset.npz` — pretrained word vectors

**Source:** GloVe 6B (Wikipedia 2014 + Gigaword 5), 100-dimensional, obtained
via `gensim.downloader.load("glove-wiki-gigaword-100")`.
Original release: <https://nlp.stanford.edu/projects/glove/> (Pennington,
Socher & Manning, EMNLP 2014).
**Licence:** Public Domain Dedication and License (PDDL) v1.0 —
<http://opendatacommons.org/licenses/pddl/> — which permits redistributing a
derived subset.
**Used by:** `lecture-notebook.ipynb` §6.

Two arrays:

- `words` — `(15095,)` object array, most-frequent-first.
- `vectors` — `(15095, 100)` `float32`; row *i* is the vector for `words[i]`.

**Why a subset rather than the full release.** The full model is 400,000 words
and a 128 MB download — too slow to watch in class and a hard network
dependency. The subset keeps the **top 15,000 words by corpus frequency** (which
is what the analogy and nearest-neighbour demos search over) plus every word
occurring in `support_articles.csv` and every word the lecture names explicitly.
Two corpus words are genuinely absent from GloVe's vocabulary — `backordered`
and `unsubscribing` — and the generator prints them rather than hiding them.

To regenerate (needs network access on first run, and downloads the full model
to `~/gensim-data/`):

```bash
uv run python week-02-vectors-similarity/data/make_glove_subset.py
```

### `help_center.csv`, `queries.csv`, `relevance.csv` — assignment corpus

**Source:** written for this course (Northwind Outfitters is a fictional
retailer).
**Licence:** CC0 / public domain — original course material.
**Used by:** the graded Week 2 assignment, which asks students to build a
similarity-search engine, compare at least three metrics, and evaluate retrieval
against the supplied relevance judgements.

`relevance.csv` uses graded judgements, so a metric can be scored with rank-aware
measures rather than a hit/miss count:

| `relevance` | Meaning |
|---:|---|
| 2 | Directly answers the query. |
| 1 | Related and useful, but not the answer. |
| 0 (absent) | Not relevant — unjudged pairs are treated as non-relevant. |

## Loading these files in a notebook

Every Week 2 notebook resolves data **local first, URL fallback**, so it works
in a fresh clone and in a Colab tab with nothing checked out:

```python
DATA_URL = ("https://raw.githubusercontent.com/prof-tcsmith/6564F26-DATA/main/"
            "week-02-vectors-similarity/data/")
CANDIDATES = [Path("data"), Path("week-02-vectors-similarity/data"), Path("../data")]

def data_path(name: str) -> str:
    for base in CANDIDATES:
        if (base / name).exists():
            return str(base / name)
    return DATA_URL + name
```
